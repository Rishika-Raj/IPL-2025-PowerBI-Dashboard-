IPL 2025 Power BI Dashboard

Project Overview

This project presents an interactive IPL 2025 dashboard created using Microsoft Power BI. The dashboard provides a visual analysis of team and player performance using key cricket performance metrics.

Tools Used

Microsoft Power BI

Power Query

DAX

IPL 2025 dataset

Dashboard Features

The dashboard includes the following visualizations:

IPL 2025 Points by Team

Team-wise Runs Analysis

Sum of Wickets by Bowler

Average Strike Rate by Team

Average Economy by Bowler

Key performance indicators for points, strike rate, and runs
